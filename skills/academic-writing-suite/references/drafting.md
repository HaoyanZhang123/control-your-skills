# 起草与重构

请求类型为「起草 / 重构」时读本文件。流程骨架在 SKILL.md §3–§6，这里给判据与诊断表。

## 1. 引言：快漏斗六步

引言要让一个**子领域之外但受过训练**的读者在几分钟内回答五个问题：为什么这个问题存在且重要、已知什么、缺什么、本文用什么方式补上、接下来会看到什么形状的研究。任何不服务这五个问题的句子都可以删。

| 步 | 功能 | 典型句数 |
|---|---|---|
| 1 | 问题存在且影响读者 | 1–2 |
| 2 | 已知什么（写成能力或证据陈述，不写文献清单） | 1–3 |
| 3 | 精确缺口 | 1 |
| 4 | 使缺口非平凡的张力 | 1–2 |
| 5 | 本文问题与方法（问题在前） | 1–2 |
| 6 | 研究形状路线图（不预告结果） | 1–3 |

比例失衡就是诊断信号：第 2 步占十句而第 3 步一句都没有，说明在写综述而不是引言。

### 缺口的写法

合格缺口 = 一个可检验的缺失 + 为什么它尚未被填补。

| 写法 | 判定 |
|---|---|
| `X 尚未在条件 Y 下测量，因此效应方向未定` | 合格：可检验、范围明确 |
| `X 的机制尚不清楚` | 偏弱：需再指名「不清楚到妨碍什么判断」 |
| `X 知之甚少` | 不合格：没有范围，读者无法判断新在哪 |
| `现有方法效果不理想` | 不合格：没有指名的机制性局限 |

### 新颖性用对比表达

指名以前做不到或未解决的是什么，现在靠什么解决。用形容词宣告新颖（`novel`、`first`）却没有指名被解除的限制，是常见空转。

## 2. 论证脊

任何论文有一条主链：**问题 → 缺口 → 做法 → 证据 → 边界化推论 → 影响**。每一节的职责是把这条链上的一段说完整，而不是自成一个主题。

诊断方法：把每节的第一句和最后一句抄成两列。若相邻两节之间出现「结论已给出后又回到背景」，说明脊断了。

### 两种通用骨架

**IMRaD（研究 / 临床 / 资源）**：问题与缺口 → 设计与人群 → 发现（按问题顺序）→ 意义与边界。

**任务-挑战-方法-验证（方法 / 算法）**：任务定义 → 现有做法的机制性局限 → 我们的机制 → 主对比与消融 → 泛化边界。

骨架不因学科改变，只改变每步的信息密度与术语。选定一种并保持到节末；中途换骨架会让读者失焦。

## 3. 重构的四个动作

1. **抽脊**：写成一句话主张 + 三条支撑。
2. **配重**：给每条支撑分配章节位置与证据预算（正文 / 图 / 补充材料）。
3. **拆借**：把串位内容搬回职责内的章节，搬运时保留指针。
4. **删余**：对每个段落做必要性测试——删掉它，读者是否仍能理解并相信主主张。

### 段落必要性测试

| 答案 | 处置 |
|---|---|
| 删掉后读者无法理解或缺少证据 | 保留 |
| 能理解，但审稿人可能会问 | 移入补充材料或回复信 |
| 能理解，且该点已在别处出现 | 删除 |

不要因为一个从句重要就保留整段；保留从句，其余移走。

## 4. 段落的三种合格形状

| 形状 | 首句 | 中段 | 末句 |
|---|---|---|---|
| 主张-证据-推论 | 主张 | 证据（含来源） | 有界推论 |
| 对比-消解 | 两个立场 | 差异分析 | 取位 |
| 条件-后果 | 条件 | 逻辑或数据 | 条件成立时的结论 |

**末句给推论或边界，不给新证据。** 新证据出现在末句说明该拆段。

## 5. Results 的证据顺序

三种可用的主线形状，选一种保持到节末：

| 形状 | 适用 | 结构 |
|---|---|---|
| 发现循环 | 研究型论文 | 观察 → 推论 → 新扰动/反证 → 更深推论 |
| 能力阶梯 | 方法型论文 | 基础能力 → 关键对照 → 增益来源 → 迁移 |
| 边界测绘 | 资源 / 临床型 | 覆盖 → 验证 → 亚组/异质性 → 适用边界 |

### 主张升级的四个合法手段

1. 新扰动（改变一个因素，观察推论是否仍成立）。
2. 反证尝试（主动设计能推翻当前推论的测试）。
3. 更强对照（同预算下更强的对手或更严格协议）。
4. 产生更深推论的边界。

**重复早先的对照到同一结论不是升级。**

### 对比与消融的公平性

- 对照必须同等预算：数据、调参、算力、评测协议。不能同等就在正文声明差异。
- 消融对应**设计选择**，一列一个选择，说明去掉它哪个机制失效。
- 「我们试过的一切」式消融表不进主线。
- 消融若成为核心发现，按核心发现处理而不是降级。

## 6. 图表与正文的分工

| 位置 | 承担 |
|---|---|
| 图注 | 面板说明、读数、必要统计（写法见 `figure-legend`） |
| 正文 | 解释、推进、与主张的关系 |
| 补充材料 | 稳健性、替代推断、溯源细节 |

**完整读数只在一个权威位置出现**，另一处只给最小判读线索。期刊要求在 caption 里写的内容就留在 caption。

同一信息在标题、段首、图注、段末各出现一次是典型冗余。处置：标题给对象，段首给主张，图注给读数，段末给推论。

## 7. 摘要

摘要是**最短的完整证据链**：只读这一段也能知道问题、答案、凭什么、边界在哪。

### 五种骨架（选一个，不混用）

| 骨架 | 结构 | 适用 |
|---|---|---|
| 挑战-贡献 | 挑战（具体限制）→ 做法 → 结果 → 影响 | 方法 / 算法类 |
| 发现驱动 | 问题 → 设计 → 主发现 → 决定性支撑 → 有界影响 | 研究类 |
| 资源型 | 缺口（缺少什么资源）→ 构建方式 → 覆盖与验证 → 访问条件 | 数据集 / 图集类 |
| 临床型 | 设计 → 人群 → 终点 → 推断 → 适用边界 | 临床 / 人群研究 |
| 假设检验型 | 假设 → 检验方式 → 结果（含阴性）→ 解释边界 | 预注册研究 |

### 数字准入测试

保留一个数字，当且仅当它满足其一：**定义主发现**、**支撑主发现**、**实质限定主发现**。不满足的删除，并说明它原本要建立什么；若答案只是「显得有数据」，就删。

### 压缩顺序

删除优先级：背景 → 方法细节 → 次要数字 → 次要主张 → 不限定主主张的修饰语。

**永不删除防止过强主张的边界句。**

### 摘要-正文一致性测试

逐句两问：这句话在正文哪里承载？找不到就删除或补正文。正文最强主张是什么？摘要是否超过它？

**摘要出现正文没有的主张是硬性缺陷。**

## 8. 结论

四要素，齐备即结束：

| 要素 | 内容 | 长度 |
|---|---|---|
| 贡献 | 本文做出了什么 | 1 句 |
| 支撑 | 靠哪类证据（不重报全部数字） | 1 句 |
| 影响 | 对有界范围意味着什么 | 1–2 句 |
| 边界 | 在什么条件下成立、什么不能推出 | 1 句 |

与摘要、Discussion 的分工：摘要给发现，讨论给机理与文献定位，结论给「什么时候可以用这个结果」。三处若出现同一句话，就有一处没做事。

**禁止**：新结果、新数字、新引用；无边界的承诺；以「未来工作」替代结论。

边界句写法：`该效应在 <体系/人群/条件> 内得到验证；由于 <设计限制>，它不能推广到 <范围>。` 弱的写法是 `未来需要更多研究来验证`（没有指明范围与原因）。

## 9. 相关工作

- 按主题聚类，不逐篇摘要。
- 每个类别给一句定位性判断（这一类做到什么、局限在哪），再落到本文取位。
- 无功能引用（引了但不服务任何判断）删除。
- 本文的定位句要能被检验：指名以前做不到什么。

## 10. 首次投稿包

| 材料 | 要点 |
|---|---|
| Cover letter | 目标期刊与文章类型 → 一句核心贡献 → 为什么适合该刊 → 常规声明 |
| Title page | 题目、作者、单位、通讯作者、字数统计 |
| Highlights / 摘要图 | 按期刊格式要求，不自行发明结构 |
| 贡献与声明 | 作者贡献、利益冲突、数据可得性、伦理声明 |
| 投稿前检查 | 页数、字数、图表数量、参考文献格式、盲审要求 |

红线：不得把一个期刊的字数或图表限制套到另一个期刊；硬数字必须标核对日期，并以目标期刊当前官方说明为准。缺的写 `[待确认: 具体问题]`。

## 11. 拒稿风险自审

四类拒稿风险：

1. 缺口不成立（这个问题已经被解决，或从来不是问题）。
2. 证据不足以支撑主张（claim 超过数据）。
3. 结论不可靠（统计、混杂、外部效度）。
4. 定位错误（投错刊、与目标读者不匹配）。

主张-证据对齐表：把正文每条主张与支撑它的图/表/统计逐行对齐。找不到支撑的主张降级或删除。

审稿人最常问的十个问题（自审清单）：

- [ ] 这个缺口是真的吗？有没有已被解决？
- [ ] 对照组是同预算的吗？
- [ ] 样本量够支撑这个效应吗？
- [ ] 这个数字的误差是什么？
- [ ] 这是相关还是因果？
- [ ] 结论能推广到哪些人群/体系？
- [ ] 消融解释了哪个机制？
- [ ] 统计检验的选择依据是什么？多重比较处理了吗？
- [ ] 数据与代码可得吗？
- [ ] 与最强的那篇相关工作相比，差异在哪？

审计输出格式：逐条给 `风险等级 | 位置 | 问题 | 证据 | 建议动作`。严重度用 `critical / major / minor`。

## 12. 自查清单

- [ ] 主链六步都能在文本中定位。
- [ ] 每节内容都在职责矩阵内，没有串位。
- [ ] 每条支撑有明确的章节位置与证据预算。
- [ ] 过渡段只承担过渡。
- [ ] 每段只有一个主功能标签。
- [ ] 缺口可检验，不是「知之甚少」。
- [ ] 路线图只讲研究形状，不预告结果。
- [ ] 摘要主张 ≤ 正文最强支撑。
- [ ] 结论无新结果、新引用。
