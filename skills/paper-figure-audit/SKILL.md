# 论文配图：去掉 AI 味

## 0. 只管一件事

管：那些**因为"图应该长这样"才被加进去**的东西。
不管：统计方法对不对、图型选得好不好、字号尺寸导出格式、版式与裁切——那是另一类问题，找期刊说明或本机的图表审计工具。

本 skill **不要求极简**。图可以复杂、可以彩色、可以有主次面板、可以有图例和标注。它只要求一件事：**加进去的每一处，都要能指向数据。**

## 1. 判据

> 图只负责让读者看见数据。任何在图里"讲道理、做辩护、做装饰"的成分，都是 AI 味。

## 2. 画之前：先写图注

一句话说清这张图要让人看见什么，再写 2–3 句图注。写不完，说明图想讲太多——拆图。
图注写好了，图里就不再需要句子。

## 3. 六种 AI 味

| | 长什么样 | 处理 |
|---|---|---|
| **替作者说话** | 图里写结论、"关键发现"、"某端系统性偏高"这类判断 | 移出图片，去图注或正文 |
| **替作者辩护** | 免责声明、"不构成…"、方法声明、身份声明、"不是显著性检验" | 移出，去 Methods / Limitations |
| **装饰** | 阴影、渐变、发光、玻璃拟态、3D、暗底、霓虹、图标、无数据含义的纹理 | 删 |
| **幻灯片化** | 大标题+副标题、指标卡、脚注层、每个面板都自我解释、编号圆圈、箭头串联 | 删，面板只留 a/b/c |
| **模板化** | 一套样式套所有图；选图型是因为看起来高级，不是因为数据适合 | 按数据重选 |
| **生成幻觉** | 图像模型"画"数据图；编造的点、纹理、箭头；数据撑不住的平滑线与显著性 | 不用，删 |

**会话语言**（"本轮""历史方案""主对话"）不是学术语言，不进图，也不进图注。

## 4. 删的时候别碰这些

去 AI 味 ≠ 删信息。下面这些都不是 AI 味，删掉就变成另一类错误：

- **n、单位、轴题、图例、必要的参考线**（0 线、1:1 线、阈值线）。
- **确实在编码信息的颜色、形状、线型**——颜色可以留，只要它对应一个变量。
- **指向数据的标注**——直接标在点上，比图例更好。
- **复杂图本身**——数据复杂，图就该复杂，不为"简洁"把分布压成一个数。
- **示意图里的插画**——标明是示意即可。

**判断**：删完之后，读者还能独立读出"画了什么、比较什么、多少样本"吗？

## 5. 交图前扫一眼

- [ ] 图里还有句子吗（结论、辩护、方法、身份、"本轮"）？
- [ ] 还有标题、副标题、指标卡、脚注层吗？
- [ ] 还有阴影、渐变、3D、图标、装饰纹理吗？
- [ ] 每个面板都在自我解释吗？
- [ ] 颜色和形状在编码信息，还是在装饰？
- [ ] 有数据撑不住的平滑线、趋势、显著性标记吗？
- [ ] 这张图是代码生成的，还是模型"画"出来的？
- [ ] 缩到终尺寸，它像论文图还是像海报？

## 6. 转介

- 统计方法与图型是否正确：交给统计核查或审稿，本 skill 不判。
- 字号、尺寸、导出、裁切：目标期刊说明，或本机图表审计工具。
- 图注的排版与语言规范：同上。本 skill 只管图注**能说什么**，不管怎么写。
